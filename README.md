## Proje Hakkında
Bu proje, 2026-2027 Güz Dönemi Web Programlama dersi kapsamında ASP.NET Core MVC (.NET 10 LTS) kullanılarak geliştirilen bir Veteriner Kliniği Randevu ve Hasta Takip Sistemidir. Sistem; klinik hizmetlerini, veteriner hekimlerin uzmanlık ve müsaitliklerini, evcil hayvanların muayene/aşı geçmişini ve randevu süreçlerini yönetirken, REST API ve MCP (Model Context Protocol) sunucusu üzerinden yapay zekâ asistanlarıyla entegre çalışmaktadır.
